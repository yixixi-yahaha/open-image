# 可配置 API 地址决策

- 状态：已接受
- 日期：2026-09-02

## 背景

Open Image 基于一个固定使用 `https://api.lumenverba.cc/v1` 的图像 Skill 改造。新项目需要适配任意 OpenAI-compatible Image API，同时避免 API 密钥因地址跳转或不可信任务地址泄露。

## 决策

1. API 根地址通过 `OPEN_IMAGE_BASE_URL` 或 `--base-url` 配置，命令行参数优先于环境变量。
2. 没有默认地址；地址未配置时在联网前报错。
3. 地址必须是 HTTPS、默认 443 端口、无用户信息、查询参数和 Fragment；允许任意 HTTPS 主机，自动去除末尾 `/`，不强制要求 `/v1`。
4. API 使用 Bearer 认证，密钥只从 `OPEN_IMAGE_API_KEY` 读取，不兼容旧变量。
5. 任务地址只接受相对地址，并基于当前 API 根地址拼接；携带认证的请求拒绝自动重定向。
6. 保留原有生成、编辑、文字、批量、尺寸/质量校验、回执和重试边界。

## 后果

用户需要显式配置地址和密钥，但可以切换不同的 OpenAI-compatible 服务。服务必须返回相对任务地址才能使用异步任务流程。公开文档和测试不包含任何真实凭据。
