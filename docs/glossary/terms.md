# Open Image 术语表

## API 根地址

用户配置的 HTTPS 服务根路径。客户端在其后拼接 `/images/generations`、`/images/edits` 和任务查询路径。

## OpenAI-compatible Image API

采用 OpenAI Images API 兼容请求/响应约定，并支持本项目所需的生成、编辑和异步任务接口的服务。

## 创建请求

可能创建并计费的图像请求。网络异常后状态可能未知，因此客户端不自动重试。

## 读取请求

查询异步任务或下载已创建图片的请求，不会创建新的图片；指定的临时网络错误最多自动重试一次。

## 相对任务地址

服务在异步创建响应中返回的相对 `Location` 地址。客户端只能基于当前 API 根地址拼接此地址，不接受绝对 URL。

## 结果回执

一次技能调用写入的版本化 JSON，包含状态、退出码、成功图片路径和错误列表。
